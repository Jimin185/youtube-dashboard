# 📬 아웃바운드 대시보드

Gmail과 연동해서 **아웃바운드 영업 메일을 자동으로 정리·관리**하는 팀용 대시보드입니다.

## 주요 기능

- **메일 자동 수집** — Gmail 보낸편지함을 IMAP으로 읽어 담당자 / 클라이언트 / 메일 제목을 자동 정리 (제목 클릭 시 메일 원문·주고받은 기록 확인)
- **답변 자동 감지** — 받은편지함에서 답장이 오면 자동으로 "답변수신" 처리 (수동 체크도 가능)
- **리마인드 자동 분류** — 답이 없는 건은 1차 발송 **15일 후 → 2차 리마인드 목록**, **한달 후 → 3차 리마인드 목록**에 자동 등장
- **대시보드에서 바로 발송** — 목록에서 체크박스로 골라 **일괄 발송**. `{{담당자}}`, `{{클라이언트}}` 변수가 받는 사람마다 자동 치환. 기존 메일 스레드에 답장으로 이어짐. 보낸 메일은 Gmail 보낸편지함에도 남음
- **직접 입력란** — 중요도(★), 공식이메일, 공식사이트, 메모를 표에서 클릭해 바로 수정
- **팀 사용** — 팀원 각자 가입 후 자기 Gmail 계정 연결. 서로의 진행 상황 조회 가능(발송은 본인 건만)

## 목록 구분

| 탭 | 조건 |
|---|---|
| 보낸 목록 | 수집된 전체 아웃바운드 (완료 제외) |
| 답변수신 | 답장이 온 건 (자동 감지 + 수동 체크) |
| 2차 리마인드 | 답 없음 + 1차 발송 후 15일 경과 |
| 3차 리마인드 | 답 없음 + 2차까지 발송 + 1차 발송 후 한달 경과 |
| 완료/제외 | 수동으로 완료 처리한 건 |

## 기술 스택

Next.js (App Router) · Drizzle ORM + Supabase(PostgreSQL) · imapflow(IMAP 수신) · nodemailer(SMTP 발송) · iron-session(로그인) · Tailwind CSS

## 배포 방법 (Vercel + Supabase)

1. **DB 연결 문자열 복사** — Supabase 대시보드 → 프로젝트 → 상단 **Connect** 버튼 → **Transaction pooler** 주소 복사 (포트 6543, `[YOUR-PASSWORD]` 부분을 DB 비밀번호로 교체)
2. **Vercel에 이 저장소 연결** 후 환경변수 등록 (`.env.example` 참고):
   - `APP_SECRET` — 32자 이상 아무 랜덤 문자열 (세션·비밀번호 암호화 키)
   - `DATABASE_URL` — 위에서 복사한 Supabase 연결 문자열
   - `TEAM_INVITE_CODE` — (선택) 설정하면 이 코드를 아는 사람만 가입 가능
   - `CRON_SECRET` — (선택) 크론 엔드포인트 보호
   - 테이블은 첫 실행 시 자동으로 생성됩니다 (별도 마이그레이션 불필요)
3. 동기화는 **대시보드를 열 때마다 자동 실행**되고(30분 간격 제한), `vercel.json`의 크론이 **매일 오전 9시(KST)** 에도 전 팀원 메일을 동기화합니다.

## 처음 사용하는 순서

1. 배포된 주소에서 **팀원 가입**
2. **설정**에서 Gmail 주소와 **앱 비밀번호** 입력 → "저장하고 연결 테스트"
   - ⚠️ Gmail 로그인 비밀번호가 아니라 [구글 앱 비밀번호](https://myaccount.google.com/apppasswords)를 만들어 넣어야 합니다 (2단계 인증 필요, 설정 화면에 안내 있음)
3. 대시보드에서 **"메일 동기화"** 클릭 → 최근 90일 보낸 메일이 자동으로 목록에 나타남
4. 이후는 접속할 때마다 + 매일 오전 9시 자동 동기화

## 로컬 개발

```bash
npm install
APP_SECRET=dev-secret-32chars-xxxxxxxxxxxxxx \
DATABASE_URL="postgres://..." \
npm run dev
```

## 참고 사항

- 메일 비밀번호는 `APP_SECRET` 기반 AES-256-GCM으로 암호화되어 저장됩니다.
- "메일 링크" 대신 **메일 원문을 대시보드 안에서 바로 보여주는 방식**으로 구현했습니다.
- 대시보드 밖(Gmail 웹)에서 직접 리마인드를 보낸 경우에도 다음 동기화 때 차수(2차/3차)가 자동 반영됩니다.
