# 📬 아웃바운드 대시보드

하이웍스 회사 메일과 연동해서 **아웃바운드 영업 메일을 자동으로 정리·관리**하는 팀용 대시보드입니다.

## 주요 기능

- **메일 자동 수집** — 하이웍스 보낸편지함을 IMAP으로 읽어 담당자 / 클라이언트 / 메일 제목을 자동 정리 (제목 클릭 시 메일 원문·주고받은 기록 확인)
- **답변 자동 감지** — 받은편지함에서 답장이 오면 자동으로 "답변수신" 처리 (수동 체크도 가능)
- **리마인드 자동 분류** — 답이 없는 건은 1차 발송 **15일 후 → 2차 리마인드 목록**, **한달 후 → 3차 리마인드 목록**에 자동 등장
- **대시보드에서 바로 발송** — 목록에서 체크박스로 골라 **일괄 발송**. `{{담당자}}`, `{{클라이언트}}` 변수가 받는 사람마다 자동 치환. 기존 메일 스레드에 답장으로 이어짐. 보낸 메일은 하이웍스 보낸편지함에도 저장
- **직접 입력란** — 중요도(★), 공식이메일, 공식사이트, 메모를 표에서 클릭해 바로 수정
- **팀 사용** — 팀원 각자 가입 후 자기 하이웍스 계정 연결. 서로의 진행 상황 조회 가능(발송은 본인 건만)

## 목록 구분

| 탭 | 조건 |
|---|---|
| 보낸 목록 | 수집된 전체 아웃바운드 (완료 제외) |
| 답변수신 | 답장이 온 건 (자동 감지 + 수동 체크) |
| 2차 리마인드 | 답 없음 + 1차 발송 후 15일 경과 |
| 3차 리마인드 | 답 없음 + 2차까지 발송 + 1차 발송 후 한달 경과 |
| 완료/제외 | 수동으로 완료 처리한 건 |

## 기술 스택

Next.js (App Router) · Drizzle ORM + libSQL(Turso) · imapflow(IMAP 수신) · nodemailer(SMTP 발송) · iron-session(로그인) · Tailwind CSS

## 배포 방법 (Vercel)

1. **DB 만들기** — [Turso](https://turso.tech) 무료 가입 → DB 생성 → URL과 토큰 복사
2. **Vercel에 이 저장소 연결** 후 환경변수 등록 (`.env.example` 참고):
   - `APP_SECRET` — 32자 이상 아무 랜덤 문자열 (세션·비밀번호 암호화 키)
   - `DATABASE_URL` — `libsql://...` (Turso URL)
   - `DATABASE_AUTH_TOKEN` — Turso 토큰
   - `TEAM_INVITE_CODE` — (선택) 설정하면 이 코드를 아는 사람만 가입 가능
   - `CRON_SECRET` — (선택) 크론 엔드포인트 보호
3. 배포하면 `vercel.json`의 크론이 **매시간 자동으로 전 팀원 메일을 동기화**합니다.

## 처음 사용하는 순서

1. 배포된 주소에서 **팀원 가입**
2. **설정**에서 하이웍스 메일 주소·비밀번호 입력 → "저장하고 연결 테스트"
   - ⚠️ 먼저 하이웍스 웹메일 → 환경설정 → POP3/IMAP 설정에서 **IMAP 사용**을 켜야 합니다
3. 대시보드에서 **"메일 동기화"** 클릭 → 최근 90일 보낸 메일이 자동으로 목록에 나타남
4. 이후는 매시간 자동 동기화

## 로컬 개발

```bash
npm install
APP_SECRET=dev-secret-32chars-xxxxxxxxxxxxxx npm run dev
# DATABASE_URL 없이 실행하면 로컬 파일 DB(data/outbound.db) 사용
```

## 참고 사항

- 메일 비밀번호는 `APP_SECRET` 기반 AES-256-GCM으로 암호화되어 저장됩니다.
- "메일 링크"는 하이웍스 웹메일이 외부 딥링크를 지원하지 않아, 대신 **메일 원문을 대시보드 안에서 바로 보여주는 방식**으로 구현했습니다.
- 대시보드 밖(하이웍스 웹메일)에서 직접 리마인드를 보낸 경우에도 다음 동기화 때 차수(2차/3차)가 자동 반영됩니다.
